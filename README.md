A modern, responsive marketing website for 360watts - combining solar energy solutions with smart home automation. Built with cutting-edge web technologies to deliver an exceptional user experience.

## 🌟 Features

### 🏠 **Interactive Solar Calculator**
- Real-time solar potential analysis
- Bill-based system sizing
- NPV (Net Present Value) calculations
- Payback period estimates
- Environmental impact metrics

### 📱 **Unified App Ecosystem**
- Real-time energy monitoring
- Smart device integration
- Automated scheduling
- Maintenance tracking
- Multi-device control

### 🎨 **Modern UI/UX**
- Responsive design for all devices
- Smooth animations with Framer Motion
- Accessible components with Shadcn UI
- Professional branding and typography

### 📄 **Multi-Page Experience**
- Homepage with hero sections and calculator
- Solutions page showcasing products
- About page with company story
- FAQ section for common questions
- Contact page with interactive map

## 🛠️ Tech Stack

- **Frontend Framework:** React 18 with TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **UI Components:** Shadcn UI
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Maps:** React Leaflet
- **Routing:** React Router DOM
- **Forms:** Native HTML5 with validation

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd project-bolt-sb1-jma3utbf/project
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to [http://localhost:5173](http://localhost:5173)

## 📜 Available Scripts

- `npm run dev` - Start development server with hot reload
- `npm run build` - Build for production
- `npm run preview` - Preview production build locally

## 🌍 Deployment

### Hostinger Deployment

This project is configured for deployment on Hostinger:

1. Build the project:
   ```bash
   npm run build
   ```

2. Upload the `dist/` folder contents to your Hostinger public_html directory

3. Configure your domain to point to the uploaded files

See `HOSTINGER_DEPLOYMENT.md` for detailed deployment instructions.
